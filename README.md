# Number Guessing Game 🎯

A small Python game where you try to guess a randomly generated number.

### How to Play

* Enter the maximum number to set the guessing range (0 to that number).
* Type your guess.
* Keep guessing until you find the correct number.
* See how many attempts it took you!

### What I Practised

* Python loops and conditionals
* User input and type conversion
* Random number generation
* Handling invalid input

### Run the Game

Make sure Python is installed, then run:

```bash
python number_guessing.py
```

This was one of my Python practice projects while learning how to work with loops, conditions, and user input.
